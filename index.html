ℹ️ Sobre nós

Informações sobre o projeto e as pessoas envolvidas.

O UniFinance PRO é um site de teste desenvolvido apenas para estudos e aprendizado. A proposta é praticar HTML, CSS e JavaScript usando uma ferramenta simples de planejamento financeiro.

Este projeto não substitui orientação financeira profissional e as projeções apresentadas são apenas simulações matemáticas.
